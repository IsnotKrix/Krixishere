# Security Policy

## Supported Versions

Only the latest production deployment of krixishere.org is actively maintained and receives security updates.

| Version | Supported |
| ------- | --------- |
| Latest (production) | ✅ |
| Older deployments | ❌ |

## Reporting a Vulnerability

If you discover a security vulnerability, please **do not** open a public GitHub issue.

Instead, report it privately by emailing:

**support@krixishere.org**

Please include:
- A description of the vulnerability
- Steps to reproduce the issue
- The potential impact
- Any suggested fix (optional)

## Response Timeline

| Stage | Time |
| ----- | ---- |
| Initial acknowledgement | Within 48 hours |
| Status update | Within 7 days |
| Fix or mitigation | Depends on severity |

## Scope

In scope:
- `krixishere.org` and all its subdomains
- Authentication and session handling
- API endpoints
- Data exposure or injection vulnerabilities

Out of scope:
- Third-party services (Vercel, Supabase, GitHub)
- Social engineering attacks
- Denial of service attacks
- Issues requiring physical access

## Disclosure Policy

We follow a **coordinated disclosure** model. Please give us a reasonable amount of time to fix the issue before any public disclosure. We will credit you in the fix if you wish.
