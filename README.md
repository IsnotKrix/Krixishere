# krixishere.org

Personal portfolio website for **Krix** — a Roblox developer with 3+ years of experience, now building on the web.

Live at [krixishere.org](https://krixishere.org)

## About

This site is a showcase of Krix's work, skills, and background. It includes:

- **Hero** — introduction with animated WebGL shader background
- **About** — background, experience, and stats
- **Projects** — featured work including Roblox projects and web builds
- **Skills** — tech stack (Roblox Studio, Lua, Next.js, TypeScript, and more)
- **Contact** — social links and email
- **Changelog** — versioned release notes with AI chat

## Tech Stack

| Layer | Technology |
|-------|-----------|
| Framework | Next.js 16 |
| Language | TypeScript |
| Styling | Tailwind CSS v4 |
| Animations | Framer Motion |
| Database | Supabase |
| Auth | NextAuth v5 |
| AI | Anthropic SDK |

## Running Locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Build

```bash
npm run build
npm start
```
